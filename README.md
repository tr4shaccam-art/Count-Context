# 🐉 ST-Omni-Block

Монитор контекста для SillyTavern без дополнительных инструментов.

## 📃 Функционал

* **Вызов через волшебную палочку:**
  Убраны все дополнительные функции, подсчет контекста открывается кнопкой «ST Info Blocks» через меню расширений.
* **Детальный подсчет токенов:**
  Анализ видимых и скрытых сообщений чата, а также вес контекста, который улетает к ИИ.
* **Трекер World Info:**
  Отслеживание активированных записей лорбука прямо во всплывающем окне с отображением их веса (в токенах).
