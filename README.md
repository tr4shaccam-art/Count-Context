# 🐉 ST-Omni-Block

Монитор контекста для SillyTavern без дополнительных инструментов.

## 📃 Функционал

* **Вызов через волшебную палочку:**
  Убраны функции, вызываемые с помощью дракона. Подсчет контекста открывается кнопкой «ST Info Blocks» через меню расширений.
* **Скрытие сообщений:**
  Сохранен инструмент скрытия/раскрытия сообщений и перенесен внутрь окна статистики (над кнопкой «Count Context») с автоматическим пересчетом токенов после выполнения.
* **Детальный подсчет токенов:**
  Анализ видимых и скрытых сообщений чата, а также вес контекста, который улетает к ИИ.
* **Трекер World Info:**
  Отслеживание активированных записей лорбука прямо во всплывающем окне с отображением их веса (в токенах).
